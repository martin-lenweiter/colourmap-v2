# Colourmap Vision Comic Panels

Raster panels for the Colourmap Vision Comic live here as compressed WebP files:

- `panel-0.webp` - Colourmap mission overview comic page.
- `panel-1.webp` - Warm paper six-panel Colourmap design comic page.
- `panel-2.webp` - Dark library/interface six-panel Colourmap design comic page.

Keep these files lightweight for weak mobile connections:

- Target width: 1200-1600 px.
- Target quality: 70-78 WebP.
- Target size: under 450 KB each, under 700 KB only when detail is essential.
- Keep text out of the artwork. The app renders readable text boxes on top.

If a raster file is missing, the reader falls back to repo-native SVG panel art so the comic still opens.
