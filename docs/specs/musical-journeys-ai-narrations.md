# Musical Journeys with AI Narrations

**Status:** Idea-stage, logged 2026-04-24. Not scheduled.

## The idea

Over time, Colourmap maps **musical journeys** — guided audio experiences that move through different:

- **Terrains** (forest, coast, desert, deep ocean, mountain, cathedral, city night)
- **Eras** (medieval chant, baroque, romantic, ambient-modern, sci-fi-future)
- **Moods** (longing, joy, grief, awakening, rest)

Each journey is a ~10–30 minute composed piece with:

- **Epic scores** — layered, orchestral, uses the Relax Sounds engine (real instruments, chants, choirs, textures)
- **AI narration** — a gentle voice that guides the listener through the terrain. Generated per session so no two are identical. Voice uses ElevenLabs or Claude voice API
- **Scene transitions** — the sound swaps layers at key moments (birds → thunder → choir → silence → cello)

## Why it matters

- Differentiates from Calm / Endel (static content) — our journeys *respond* and *vary*
- Uses existing engine — layers + melodies + volume control already there
- Adjacent to ColourStudios (Vol. II) — a journey is a pre-composed loop arrangement
- Gives Martin a canvas for *composing* rather than just tooling

## Minimum viable journey

1. One terrain (forest-dawn)
2. One 12-minute score: 3 movements (arrival, wandering, rest)
3. ~8 AI-narrated prompts at key moments ("feel the dew under your feet")
4. Cross-fade transitions between movements
